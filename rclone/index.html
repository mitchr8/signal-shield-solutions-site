MOLONLABE Rclone

A privately operated Google Drive integration using the open-source rclone command-line tool and a dedicated Google OAuth desktop application.

Purpose

This integration allows the account owner to access and manage their own Google Drive files from an authorized Windows computer for file transfer, organization, backups and explicitly started automation tasks.

How access works

The owner authorizes access through Google's OAuth consent flow. The integration may request full Google Drive access to list, read, create, update and delete files, as directed by the owner. OAuth credentials are kept on the owner's computer, not on this public website.

This is a personal desktop integration, not a public file-management service. This website does not provide sign-in, execute Drive operations, or receive Drive file contents.

Data handling

See the MOLONLABE Rclone Privacy Policy for details on Google user data access, storage, use and revocation.
