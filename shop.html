FAQ

How the storefront works.

Do I have to leave the site to check out?

If an Etsy listing exists, the purchase button opens that listing so checkout and payment stay inside Etsy’s flow.

What if I want a different size or color?

Tap Ask about this print and tell us what you’d like changed. We’ll quote it.

Why do some products open on Etsy and others do not?

Some prints are already listed on Etsy. Others are still being photographed and listed, but you can order them now by asking.

Can I see the printer running?

Yes. Use the live prints page to watch active runs and see the current print details beside the stream.
